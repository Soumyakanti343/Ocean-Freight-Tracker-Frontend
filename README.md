# 🚢 Ocean Freight Rate & Shipment Tracker

A modern, responsive landing page showcasing the **Ocean Freight Rate & Shipment Tracker** — a web application designed to simplify ocean freight rate comparison, shipment monitoring, invoice verification, and email-based rate updates.

---

##  About the Project

The Ocean Freight Rate & Shipment Tracker aims to make freight management simpler by bringing essential shipping operations together in one place.

The application helps users compare carrier rates, track shipments, identify potential invoice overcharges, and process freight rate updates from emails.

This repository contains the **frontend landing page** created to showcase the project, its features, technologies, and developer information.

##  Features

###  Overview Dashboard
- View a summary of shipment information.
- Monitor important shipment statistics.
- Explore shipment data through visualizations.

###  Freight Rate Search
- Compare ocean freight rates across carriers.
- Search rates for different container sizes, including 20ft and 40ft.
- Identify the lowest available rate for a route.

###  Shipment Tracker
- Track shipment information and delivery status.
- Monitor statuses such as In Transit, Delivered, and Delayed.
- Manage shipment records.

###  Invoice Checker
- Compare invoice charges against available carrier rates.
- Identify potential overcharges.
- Upload invoice data for checking.

###  Email Updates
- Process email-based freight rate updates.
- Extract relevant rate information from email content.
- Avoid processing duplicate email records.

###  Responsive Landing Page
- Modern, professional design.
- Responsive navigation for mobile devices.
- Dedicated project overview and feature sections.
- Technology stack and developer information.
- Direct links to the live application and developer profiles.

##  Technologies Used

### Landing Page
- **HTML5** — Page structure and content.
- **CSS3** — Styling, layouts, responsiveness, and animations.
- **JavaScript** — Navigation interactions, smooth scrolling, and dynamic footer year.

### Main Application
- **Python** — Application logic and data processing.
- **Streamlit** — Interactive web application interface.
- **SQLite** — Local database storage.
- **CSV** — Rate, shipment, and invoice data handling.
- **Email Parsing** — Extracting information from email-based rate updates.
